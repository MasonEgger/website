# Talk Python to Me #515: Durable Python Execution with Temporal

I joined Michael Kennedy on Talk Python to Me to discuss Temporal, a durable execution platform that enables developers to build resilient Python applications.

<!-- more -->

In this episode, we explore how Temporal handles failures automatically by maintaining event history and resuming execution after crashes, rather than scattering retry logic throughout your code. We discuss workflows vs. activities, deterministic execution, intelligent retry policies, long-running workflows with timers and signals, and the Python SDK implementation with async/await. We also touch on polyglot workflow interoperability and testing workflows with time-skipping capabilities.
